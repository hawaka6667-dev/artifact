# Reference photograph

`mosquitoes-china-cdc.png` is the photograph used to model the two mosquitoes on the page: a female northern house mosquito (淡色库蚊, top) and a female Asian tiger mosquito (白纹伊蚊, bottom).

Source credit printed on the image: 中国疾病预防控制中心 (Chinese Center for Disease Control and Prevention). The image is not covered by this repository's own rights notice; it stays with its original owner and is kept here only as the modeling reference.
